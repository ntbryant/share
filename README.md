# share.nickturmanbryant.com

One folder per idea. Each page is authored as a fragment (`page.html`, `<name>.page.html`) and wrapped into standalone HTML by `./build.sh`.

- `mile/` → share.nickturmanbryant.com/mile (full guide), /mile/start (getting-started guide)

To add an idea: create `<idea>/page.html`, run `./build.sh`, commit, push.
